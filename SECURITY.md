# Security policy

## Supported versions

Only the latest release gets fixes. grebe is pre-1.0, so a fix ships as a new
release rather than a backport.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ncrzw9/grebe/security/advisories/new)
with the version, how to reproduce it, and what an attacker gains.

grebe is maintained by one person in their own time, so there is no SLA; expect
an acknowledgement within a week. Once a fix is released the advisory is
published, crediting you unless you'd rather not be.
